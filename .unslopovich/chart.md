# Chart

Stack: Static HTML5, CSS3, Vanilla JavaScript (ES6)
Platforms: Web (Desktop, Tablets, Mobile browsers)
Visits: on

## Top tasks
1. Consultar quintales (QQs) totales y desglose diario o por rango de fechas (index.html)
2. Revisar indicadores OEE (Disponibilidad, Desempeño, Calidad) del turno o periodo (metricas.html)
3. Monitorear tiempos de ciclo promedio en trenes, verticales y guardiolas (tiempos.html)
4. Identificar códigos de equipos, motores y CCMs asignados (Motores.html)

## Users and context
Supervisores de planta, operadores y jefes de beneficio húmedo/seco de café. Uso mixto: teléfonos móviles en piso de secadoras (polvo, ruido, luz diurna) y monitores de oficina.
